Fitness Tracker

The public Pages site contains the app only; measurements and workouts live in your configured private GitHub repository. Each browser needs a GitHub token once.

1. Open GitHub and create a token for this device. The link pre-fills the owner, token name, no expiry, and Contents: Read and write.

Create token on GitHub

On GitHub, the only manual permission step is Repository access → Only select repositories → Fitness-Tracker-Data. Generate the token and copy it.

Open GitHub token settings

2. Return here and paste the copied token.

You do not need to move the token between devices: on another phone or computer, use the GitHub link above and create another token there. Saved fitness data stays in the private repository. Remembered tokens are kept in this browser and are never written to either repository.
